# 로컬 자료와 개인정보

설치 앱은 화면과 계산에 필요한 파일을 로컬에 포함합니다. 계정, 원격 분석, 광고, 원격 오류 전송 기능은 구현하지 않습니다. 앱 화면의 HTTP/HTTPS 요청과 외부 창은 차단합니다. 개발 의존성 설치와 도구 준비는 별도이며 인터넷을 사용할 수 있습니다.

실험 자동 저장, 창 위치와 실행 로그는 Lens Lab 로컬 프로필에 남습니다. 열기·저장 대화상자에서 직접 선택한 파일을 사용하며 원문 복구를 선택하면 해당 원문을 로컬 파일로 내보냅니다. 파일에 붙인 비교 이름과 직접 만든 데이터도 파일에 포함되므로 공유 전 확인하세요.

문제 보고는 사용자가 직접 보내는 자료에 한합니다. 테스트·진단 기록에는 로컬 파일 경로, 실행 환경, 실험 내용이 들어갈 수 있습니다. 민감한 정보와 불필요한 원문을 제거하고 필요한 재현 단계만 공유하세요.
