# Lens Lab 1.1 상세 관찰 개선

이 문서는 1.1 개선 브랜치의 범위입니다. 공개된 1.0 설치 파일과 구분하며, 새 설치 파일의 공개 여부는 릴리스 페이지에서 확인합니다.

## 계산이 설명하는 것

기존 얇은 렌즈·원형 동공 계산에서 광선의 수렴도, 조리개 면적과 명목 f/D, 현재 스크린의 좌표 배율과 한 점의 흐림 크기를 도출합니다. 부품을 선택하면 그 부품에 관련된 값과 해석 범위를 함께 표시합니다.

- 렌즈: 초점거리, 렌즈에서 출사하는 한 표적점의 광선 수렴·평행·발산, 실제 상의 위치와 배율.
- 조리개: 원형 열린 면적, 명목 f/D, 상대 수집 광량, 기하학적 흐림과 허용 스크린 위치 폭.
- 스크린: 현재 거리 s, 한 점의 흐림 원 중심 배율 B=−s/u, 동공 좌표 배율 C, 흐림 반지름과 선형 영상 배율 인자.
- 시험대와 이동대: 렌즈 기준 실제 위치, 표시 치수, 레일과 교차한 허용 위치 구간. 레일 밖 실상이나 표적 쪽 허상의 위치를 레일 끝으로 바꾸지 않습니다.
- 전원선: 일정한 발광 표적이라는 모형의 가정과 상대 광량만 설명합니다. 별도 전기 회로나 광원의 와트 출력을 계산하지 않습니다.

같은 점에서 나온 광선이 이상적인 상에서 만나는 배율 m=−v/u와, 현재 스크린에 펼쳐진 흐림 원 중심의 배율 B는 서로 다릅니다. 허상의 배율이 양수여도 앞쪽 스크린의 B는 음수입니다. u=f에서는 같은 점의 광선이 평행할 뿐이며 유한한 상 위치·배율을 임의로 만들지 않습니다.

## 고정한 물체에 대한 스크린 허용 위치

흐림 반지름 0.1 mm 이하라는 명시적인 기준으로, 현재 물체거리·초점거리·조리개를 고정한 스크린 위치를 계산합니다. 실제 이동 범위 100–900 mm와 교차하지 않으면 허용 위치가 없다고 표시합니다. 초점이 조금 멀어 레일 밖에 있어도 허용 구간 일부가 레일에 들어올 수 있습니다.

기본 f=150 mm, u=300 mm, D=18 mm에서는 약 296.667–303.333 mm가 허용됩니다. 구경을 6 mm로 줄이면 290–310 mm로 넓어지고 수집 광량은 1/9이 됩니다. 평행·발산 조건에는 이 0.1 mm 기준을 만족하는 전방 스크린이 없습니다. 이 값은 물체거리의 피사계심도가 아니며 제조 공차나 초점 조절 장치의 실제 정밀도를 뜻하지 않습니다.

## 원래 기록과 광량 표현

상세 계산은 광학 설정이나 원래 해를 수정하지 않습니다. 기존 `thin-lens-paraxial-1` 모형, 프로젝트 형식, 저장한 비교 조건과 영상 투영 계산을 유지합니다. 새 관찰값은 현재 설정에서 다시 계산하며 저장 형식에 별도 상태를 넣지 않습니다.

상대 수집 광량은 D=18 mm·u=300 mm를 기준으로 합니다. 스크린의 선형 영상 배율 인자는 표적 분포와 흐림 원판의 합성곱에 곱하는 값입니다. 두 값을 실제 조도, lux, W, 표시 픽셀 값 자체로 부르지 않습니다. 48 mm 스크린 밖 빛은 잘리며 고정 노출 영상의 밝기를 자동으로 다시 맞추지 않습니다.

## 계산하지 않는 현상과 검증

표시 유리의 곡률·두께에 따른 면별 굴절, 실제 유리 재질, 수치개구, 회절·간섭·색수차·구면수차·비네팅·카메라 센서·눈의 적응을 추가로 계산하지 않습니다. 조리개가 작아지면 실제 광학 해상도가 언제나 좋아진다는 의미도 아닙니다. 구조 표현의 수정은 광학 모형의 정확도나 제조 가능성을 새로 보증하지 않습니다.

12개 새 수치 검사는 독립 광선으로 중심·동공 배율과 흐림을 재구성하고, 허용 위치 경계와 레일 교집합, 무한대·허상·초점거리 이웃 입력, 구경 변화와 선형 투영 적분, 원본 불변성을 확인합니다. 화면 조작·3D 표현·파일 호환성·설치 확인은 별도의 통합 검증 대상입니다.
