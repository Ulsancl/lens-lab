# 문제 보고

재현할 수 있는 작은 실험과 발생 순서를 남겨 주세요. 앱 버전, Windows 버전, 화면 배율·해상도, GPU, 예상한 결과와 실제 결과를 함께 기록하면 원인 파악에 도움이 됩니다. 초점 문제는 초점거리·물체거리·스크린거리·조리개 지름 네 수치가 필요합니다.

실험 파일은 공유 전 비교 이름과 내용을 확인하세요. 손상되거나 새 버전인 파일은 원문 내보내기로 따로 보관하고 덮어쓰지 마세요. 화면이 보이지 않는 경우 창을 닫고 다시 시작한 결과와 오류 문구를 기록합니다. 개발 검사 로그에는 개인 경로가 들어갈 수 있으므로 그대로 공개하지 마세요.

문제 보고와 검사 기록은 지원 응답 시간, 모든 장치 호환성 또는 유료 유지보수 계약을 보장하지 않습니다.
