# 안전한 빌드와 검증 산출물

배포 도구는 입력 파일과 상위 폴더의 심볼릭 링크·정션·특수 파일을 거부합니다. 웹과 데스크톱 빌드는 검증한 소스와 운영 의존성을 임시 디렉터리로 복사하고 그 사본으로 번들을 만듭니다. 빌드가 성공하면 완성된 디렉터리를 게시합니다. 개발 서버는 생성된 번들, 패키지, 진단 및 임시 디렉터리의 HTTP 제공을 차단합니다.

브라우저·데스크톱 테스트도 새 임시 디렉터리에 기록한 다음 종료 시 기존 output 경로로 결과를 게시합니다. 기존 결과 경로에 연결 파일이 있으면 다른 위치에 기록하지 않고 실패합니다. 빌드는 해당 사용자가 소유한 깨끗한 작업 공간에서 실행하세요. POSIX에서는 다른 사용자가 쓸 수 있는 산출물 부모 폴더도 거부합니다.

Windows에서는 작업 폴더와 도구 캐시를 NTFS 권한으로 보호하세요. 빌드할 소스와 도구 자체는 신뢰된 체크아웃에서 가져옵니다. CI는 `npm ci --ignore-scripts`로 설치하고 Electron과 Chromium만 명시적으로 준비합니다. Electron은 고정 npm 패키지에 포함된 체크섬을 사용합니다. NSIS와 Windows 도구는 잠긴 electron-builder의 아카이브 해시를 사용하며 CI는 새 빌더 캐시를 사용합니다. Playwright는 고정된 버전의 검사 브라우저를 HTTPS로 내려받습니다. 이 검사 브라우저는 설치 파일에 포함되지 않습니다.
