# 완성 기준과 한계

이 문서는 Lens Lab 1.0의 유한한 공개 범위를 정하는 기준입니다. 실제 통과 여부와 배포 상태는 각 버전의 결과 기록을 따릅니다. 이 문서나 내부 검사는 외부 사용자 연구·실제 판매·유료 지원을 검증했다는 뜻이 아닙니다.

- 단일 수렴 얇은 렌즈, 평면 발광 표적과 스크린, 세 초점거리와 정해진 거리·구경 범위를 다룹니다. 수치·광선·투영 영상은 같은 조건으로 일치해야 합니다.
- 세 실험은 실제 조작과 관찰에 연결된 완료 결과를 갖습니다. 실상·허상·무한대와 레일 밖 상을 사실과 다른 유한 초점으로 바꾸지 않습니다.
- 카메라·선택·표시 조작은 광학 조건을 바꾸지 않습니다. 표적·스크린 이동은 숫자 입력과 동일하게 계산합니다. 1024 px와 390 px 폭에서도 필요한 조작에 접근할 수 있어야 합니다.
- 부품 이름표와 연결선이 실제 부품을 가리키고, 명시한 부품 가까이 보기가 관찰 위치를 맞춰야 합니다. 현재·보관 영상을 동일한 물리 영역·표본 크기·화면 크기·노출로 비교하고, 보관 영상과 현재 계측값을 구분해야 합니다.
- 설정·비교·카메라 저장과 복원이 일치하며 손상·미래 버전 원문은 보호합니다. 소스 계산 검사, 브라우저 상호작용, 네이티브 파일·메뉴·재시작과 실제 설치를 구분해 확인합니다.
- 새 설치와 기존 버전의 업데이트는 해당 결과 기록에 따릅니다. 제거 설정의 정적 확인을 실제 제거 실행 검사로 주장하지 않습니다.
- 라이브러리 고지, 제품 정체성, 설치 파일 해시와 실제 패키지 내용이 일치해야 합니다. 서명과 자동 업데이트는 제공하지 않습니다.

하드웨어 확인은 기록된 환경에 한정합니다. 대상은 Windows 11 x64이며 실제 관찰에 사용하는 환경은 RTX 5080, 화면 배율 150%입니다. 특정 버전의 통과 여부는 그 버전의 기록을 확인하며 다른 GPU·운영체제·원격 데스크톱·모든 화면 배율의 호환성으로 확대하지 않습니다.

회절, 색수차·구면수차, 유리 두께와 실제 유리의 투과율, 센서 노이즈, 다중 렌즈, 눈의 지각과 안전한 실물 실험 지침은 범위 밖입니다. 투영은 유한 격자에 계산한 기하학적 영상이고 상대 밝기를 표시합니다. 실제 광학 설계·측광·카메라 노출·의료·안전 판단에 사용하는 도구가 아닙니다.
