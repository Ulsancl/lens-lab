# 원리 참고와 자산 출처

2026-10-01 확인. 아래 자료는 원리·실험 구성의 참고문헌입니다. 해당 사진·문구·제품 도면·프로그램을 앱에 복제하지 않습니다.

1. [OpenStax, University Physics 3 — Thin Lenses](https://openstax.org/books/university-physics-volume-3/pages/2-4-thin-lenses): 얇은 렌즈식, 배율 부호, 실상·허상과 초점에 놓인 물체점의 평행 출사광을 설명합니다. 앱의 수식·독립 수치 검사와 한국어 설명은 직접 작성합니다.
2. [Edmund Optics — System Throughput, f/#, and Numerical Aperture](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/lens-iris-aperture-setting/): 구경과 빛의 통과량·초점 범위 및 회절의 관계를 다룹니다. 앱의 상대 광량을 실제 조도나 특정 카메라 노출로 해석하지 않는 근거입니다.
3. [PASCO — Optics System Guide](https://www.pasco.com/products/guides/optics): 광학 레일 위의 광원·렌즈·스크린을 이용한 실험 구성을 참고했습니다. 실험대의 치수·외형·기하·표적·아이콘은 자체 설계이며 제조사 제품의 복제품이 아닙니다.

앱의 초점거리·거리·조리개 범위와 상대 광량 기준은 교육용 설계값입니다. 공인 장비 사양이나 교정된 측정값으로 인용하지 않습니다. 라이브러리 배포 조건은 [제3자 고지](THIRD-PARTY-NOTICES.md)와 별도로 관리합니다.
