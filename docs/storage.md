# 저장과 복원

프로젝트는 `lens-lab-project`, 스키마 1, 모형 `thin-lens-paraxial-1`을 명시한 JSON입니다. 초점거리·물체거리·스크린거리·조리개 지름 네 수치, 이름과 조건을 가진 비교 기록 하나, 광선·초점·구조·이름표 표시, 선택 부품과 카메라를 보관합니다. 시간·재생 상태·계산된 상·투영 픽셀·안내 진행은 보관하지 않습니다. 결과는 원래 광학 조건에서 다시 계산합니다.

파일 읽기는 수치를 자동 보정하지 않습니다. 알 수 없는 항목·버전·부품, 범위 밖 수치, 잘못된 카메라와 10 MiB 초과 파일을 현재 실험과 원문을 바꾸지 않고 거부합니다. 초점거리는 150 / 225 / 300 mm만 허용합니다. Windows UTF-8 BOM 한 개는 허용하고 저장된 비정수 거리와 카메라를 임의 반올림하지 않습니다.

브라우저 자동 저장 키는 `lens-lab-project-v1`입니다. 손상되었거나 새 버전으로 작성된 원문은 덮어쓰지 않고 원문 내보내기를 제공합니다. 새로 관찰하는 작업은 별도 파일로 보관하세요. 자동 저장은 브라우저나 앱의 로컬 프로필에 있으므로 브라우저 데이터 삭제, 프로필 삭제 또는 저장 장치 문제에 대비한 외부 백업을 대신하지 않습니다. 다른 브라우저에서 연 화면과 설치 앱의 프로필은 서로 별개입니다.

설치 앱은 같은 검증기로 파일을 확인합니다. 저장은 목적지와 같은 폴더의 새 임시 파일에 완전한 내용을 쓰고 디스크에 반영한 뒤 이름을 바꿉니다. Windows의 일시적 파일 공유 오류는 총 775 ms의 대기를 포함해 최대 6회 교체를 시도하며 매번 실제 부모 경로와 일반 파일 여부를 다시 확인합니다. 기존 목적지를 먼저 삭제하지 않습니다. 실패 시 만든 임시 파일만 정리하고 오류를 알립니다. 전원 차단이나 디스크 고장까지 복구를 보장하지는 않습니다.
