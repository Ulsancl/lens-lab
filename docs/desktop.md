# Windows 앱

대상은 Windows 11 x64입니다. `npm run package:desktop`은 `release/windows/Lens-Lab-Setup-1.0.0.exe`와 `.sha256`을 생성하며 자동 게시하지 않습니다. 파일 이름의 버전은 package.json을 따릅니다. 배포된 설치 파일과 해시는 [최신 릴리스](https://github.com/Ulsancl/lens-lab/releases/latest)에서 확인하며 실제 설치·하드웨어 확인 범위는 해당 결과 기록을 따릅니다.

앱 이름은 Lens Lab, ID는 `com.lenslab.app`, 로컬 화면 주소는 `app://lens/`입니다. 사용자 프로필은 Windows 앱 데이터 폴더의 Lens Lab입니다. 도움말의 저장 폴더 열기에서 접근합니다. 창 크기·위치는 프로필에 보관하고 작업 영역 밖으로 나간 창은 사용 가능한 화면 안으로 복원합니다.

파일 메뉴는 새 실험·열기·저장입니다. 실험 메뉴의 **광선 표시 전환**은 광학 조건을 유지한 채 광선 표시만 바꿉니다. 보기의 3D 크게 보기, 도움말의 사용 안내와 프로그램 정보를 사용할 수 있습니다. Ctrl+N/O/S는 새 실험/열기/저장, Ctrl+Shift+R은 광선 표시, Ctrl+Shift+F는 큰 화면, F1은 도움말입니다. 파일 대화상자나 자료 처리 도중 창을 닫으면 종료 확인을 표시합니다.

설치 앱은 코드 서명되지 않아 Windows의 게시자·평판 경고가 표시될 수 있습니다. 자동 업데이트는 없습니다. 기존 실험을 파일로 보관하고 앱을 닫은 뒤 새 설치 파일을 실행합니다. 설치 앱 실행에는 Node.js나 개발 서버가 필요하지 않습니다. 제거 설정은 사용자 앱 데이터를 자동 삭제하지 않도록 구성했습니다. 제거 프로그램과 설정의 정적 확인은 실제 제거 실행 검사와 구분합니다.

개발 검사는 절대 경로 `LENS_LAB_DATA_DIR`로 독립 프로필을 지정합니다. `LENS_DESKTOP_EXE`는 생성된 독립 실행 파일의 절대 경로를 지정할 때 사용합니다. 일반 사용에는 두 변수가 필요하지 않습니다. 실제 화면을 사용하는 검사는 한 번에 하나만 실행합니다.
